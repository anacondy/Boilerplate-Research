# PART 1 — Knowledge & Reasoning Baseline

## 1.1 The "hard problem of consciousness": current consensus and positions

The **hard problem** (Chalmers, 1995) is the explanatory gap between physical/functional brain processes and *phenomenal experience* — why physical processing should be accompanied by "something it is like." There is **no scientific consensus**; the field explicitly reports that no single theory commands majority agreement (Francken et al., 2022 survey, *Neuroscience of Consciousness*). The main positions:

- **Physicalism** (default working assumption in most neuroscience): consciousness is fully constituted by physical processes. Variants: identity theory, functionalism, reductive and *non-reductive* physicalism. Remains the most popular stance among researchers [1, 2], though it faces the explanatory gap and the "hard/easy problem" distinction.
- **Dualism** (substance/property): mind is non-physical (e.g., Chalmers; "naturalistic dualism"). A minority position; critics note it faces the interaction problem and is harder to make scientific.
- **Panpsychism** (incl. *Russellian monism* and *cosmopsychism*): consciousness is fundamental and widespread; micro-level entities have proto-experience. Has seen a notable **resurgence** post-2023 (Koch, Goff; IIT is often characterized as a "scientific panpsychism"). Key open challenge is the **combination problem** (how micro-subjects compose into one macro-subject) [3, 4].
- **Illusionism** (Dennett, Frankish, Graziano's *Attention Schema Theory*): phenomenal consciousness as we introspect it is an illusion; the hard problem is dissolved rather than solved. Strongly counterintuitive, so many reject it, but it remains a live, active program [1].
- **IIT / other "quantitative" programs** (Tononi et al.): aim to make consciousness measurable (Φ); often entwined with panpsychist consequences (see Part 2).

**Significant developments after 2023:**
- **The COGITATE adversarial collaboration** (Ferrante et al., *Nature*, April 2025) directly pitted IIT against Global Neuronal Workspace Theory in a preregistered, theory-neutral, multimodal study (fMRI+MEG+iEEG, n=256). It *challenged core tenets of both theories* rather than vindicating either — widely covered as a landmark for a "quantitative framework for systematic theory testing" [5, 6].
- **AI-consciousness assessment**: the 2023 *Nature* review "Consciousness in artificial intelligence" (Butlin, Long, Chalmers, et al.) proposed indicator-based assessment; this agenda has continued into 2025–26 (e.g., theoretical marker lists, IEEE/standardization discussions), keeping the hard-problem debate relevant to frontier models [7].
- **Re-centering on the "real/pretty hard problem"**: philosophers of science increasingly argue progress should target the *"real problem"* of consciousness (Anil Seth) or the *"pretty hard problem"* (Chalmers/Aaronson) — i.e., finding the mechanism that distinguishes conscious from unconscious processing — while treating the metaphysical "hard" question as perhaps underdetermined [1].
- **Growing pluralism/methodology focus**: surveys and adversarial-collaboration frameworks stress that empirical adjudication between theories (not armchair debate) is now the field's central task [2, 5].

## 1.2 Transformer KV cache during inference

**What it is.** During autoregressive generation, each transformer layer computes an attention matrix between queries and keys. The **key-value (KV) cache** stores, for every past token and every attention head/layer, the *key* and *value* vectors produced by that layer, so that when generating the next token you need only compute the new token's query against the cached keys (no need to recompute earlier tokens' keys/values).

**Memory complexity.**
- Per token stored: `2 × (num_layers) × (num_heads) × (head_dim)` scalars (one key + one value).
- With `L` layers, `H` heads of dimension `D`, batch size `B`, and sequence length `S`, total cache size ≈ `2 · B · L · H · D · S` bytes (× bytes per element, e.g., FP16 = 2 bytes).
- **Scaling**: memory grows **linearly with sequence length** `S` and with `L·H·D` (the model's parameter dimension) — i.e., `O(L·H·D·S)` per batch. For very long contexts this dominates inference cost and can even exceed weights.

**Common optimisations.**
- **Multi-Query / Grouped-Query Attention (MQA/GQA)**: share the keys/values across heads (GQA = a small number of *groups* of query heads share K/V). Shrinks the `H` factor in cache and bandwidth by ~H/groups, cutting KV cache and memory bandwidth substantially with minor quality loss (used in Llama-2/3, Mistral, Gemini).
- **PagedAttention / KV-cache paging**: store KV blocks in non-contiguous memory pages to eliminate fragmentation and allow *prefix sharing* (used by vLLM). Improves throughput and memory efficiency in serving engines.
- **Sliding-window / local attention**: only cache a window of recent tokens, capping cache growth for long sequences (though it reduces effective context; e.g., Mistral).
- **Quantisation**: store KV in FP8/INT8/INT4 (e.g., KV cache quantisation) to halve/quarter memory.
- **Chunked prefill / continuous batching**: optimise memory scheduling between the prefill and decode phases.
- **Eviction/compression**: h2 (heavy-hitter) and token-dropping heuristics retain "important" tokens.
- **FlashAttention**: though primarily a compute/IO optimisation, by avoiding materialising full attention matrices it reduces the memory bandwidth pressure that makes KV caching dominant.

## 2.2 Synthesis (comparison of empirical status of IIT vs GWT)

Over 2022–2026, the empirical status of IIT and GWT has been transformed less by new positive evidence than by the field's first large-scale, preregistered **adversarial testing**. The defining result is the COGITATE collaboration, which executed a theory-neutral protocol (preregistered in Melloni et al. 2023) across 256 participants with fMRI, MEG, and intracranial EEG. Its headline finding is that **neither theory was vindicated**: conscious content was decodable in posterior, ventrotemporal, and to a degree inferior-frontal cortex, but IIT's predicted *sustained intra-posterior synchronization* and GNWT's predicted *prefrontal ignition at stimulus offset* both failed to appear. The study concluded that both theories face "substantial challenges," and it proposed a move toward a quantitative framework for systematic theory-building.

Interpretation of these results is sharply contested. The GNWT proponents (Naccache, Sergent, Dehaene, et al. 2025) rebut that the outcome actually supports core GNWT claims — transient brain-wide activation and prefrontal–sensory synchrony within the expected time window — and that the "missing" offset-ignition was never a core prediction (it is only expected when subjects attend to stimulus offset, which the no-report design precluded), and that weak PFC decoding is a decoding-methodology artifact rather than evidence of absent broadcast. Thus what looks like a GNWT failure on one reading is a GNWT confirmation on another — a sign that the two camps' *precommitments* still heavily shape interpretation.

Alongside COGITATE, two independent strands have undercut IIT's formalism. Hanson & Walker (2023) showed that Φ is **non-unique** in IIT 3.0 — a single system can legitimately yield many Φ values, sometimes straddling the conscious threshold — rendering the theory's central quantity mathematically ill-defined as a decisional measure. Merker, Williford & Rudrauf (2022) argued Φ measures network integration, not consciousness, and that IIT's panpsychist consequences (conscious power grids) are a reductio. These formal critiques do not directly test GWT, but they mean that even a successful experiment cannot cleanly "measure" IIT's central variable.

GWT's empirical status is comparatively more tractable, because its predictions (ignition, reportability, fronto-parietal broadcasting) are concretely testable. The COGITATE data partly challenge the frontal-centric version; supportive evidence for a *distributed/synergistic* workspace comes from intracranial work (e.g., Luppi et al. 2024 identifying a posterior "synergistic workspace") and from non-brain demonstrations (a computational "global workspace" in transformer models, discussed in 2025–26). Yet GWT remains philosophically limited: it addresses *access* consciousness and says little about *phenomenal* consciousness (the access/overflow debate), a limitation acknowledged even by its proponents.

**Open questions.** (1) Can the field reach *shared, pre-registered operationalisations* of "ignition," "synchronization," and "content decoding" so that re-analysis converges instead of being theory-laden? (2) Is Φ (or any single scalar) salvageable as a well-defined quantity, or must IIT be reformulated? (3) Do no-report paradigms eliminate a hidden role for attention/report that biases tests against GWT? (4) Can AI "workspace" models inform the NCC, or are they merely functional analogies? (5) Will future adversarial collaborations (e.g., IIT vs predictive processing under ARC-INTREPID) similarly constrain or falsify the leading theories? Overall, the current empirical picture is best summarised as **"mixed and underdetermined"**: both theories explain subsets of the data, both have survived falsification attempts only partially, and neither has decisively outperformed the other — exactly the state of play that motivates more rigorous, quantitative, collaborative science.

#!/usr/bin/env python3
"""
Part 3A — Download the abstract of the most-cited IIT paper, extract text,
and compute the top-15 non-stop words.

Most-cited IIT paper found during the literature search:
    Tononi, G., Boly, M., Massimini, M., & Koch, C. (2016).
    "Integrated information theory: from consciousness to its physical substrate."
    Nature Reviews Neuroscience, 17(7), 450-461.  DOI: 10.1038/nrn.2016.44
    (This is the standard, most-cited IIT citation in the field.)

The full text is paywalled but the abstract is freely available on the
publisher page, which is what this script downloads.
"""

import re
import requests
from bs4 import BeautifulSoup
from collections import Counter
from pathlib import Path

# ---------------------------------------------------------------------------
# 1. Config / paths
# ---------------------------------------------------------------------------
DOI = "10.1038/nrn.2016.44"
ARTICLE_URL = "https://www.nature.com/articles/nrn.2016.44"

RAW_TXT = Path("part3/iit_nrn2016_abstract.txt")
FREQ_CSV = Path("part3/top15_words.csv")

HEADERS = {
    "User-Agent": (
        "Mozilla/5.0 (Windows NT 10.0; Win64; x64) "
        "AppleWebKit/537.36 (KHTML, like Gecko) Chrome/120 Safari/537.36"
    )
}

# A small English stop-word list (common function words + IIT-specific filler).
# Kept self-contained so the script runs with only requests + bs4 installed.
STOPWORDS = set("""
a an and the or but if then else of to in on at for with by from as is are was
were be been being it its it's this that these those i you he she we they me
him her them my your his their our us am not no do does did have has had will
would can could should may might must about into over under again further once
here there when where why how all any both each few more most other some such
only own same so than too very s t just don now d m ll re ve y up out off
down above below whom whose what which who upon vs per via e.g ie
that's let us etc al doi nature reviews neuroscience et
""".split())

# ---------------------------------------------------------------------------
# 2. Download + extract the abstract
# ---------------------------------------------------------------------------
def fetch_abstract(url: str) -> str:
    """Return the 'Abs1-content' abstract text from a Nature article page."""
    resp = requests.get(url, headers=HEADERS, timeout=30)
    resp.raise_for_status()
    soup = BeautifulSoup(resp.text, "html.parser")
    node = soup.find(id="Abs1-content")
    if node is None:
        node = soup.find("div", class_="c-article-section__content")
    if node is None:
        raise RuntimeError("Could not locate the abstract in the HTML.")
    # Collapse whitespace / newlines into a single clean string.
    return re.sub(r"\s+", " ", node.get_text(" ", strip=True)).strip()

# ---------------------------------------------------------------------------
# 3. Word-frequency analysis
# ---------------------------------------------------------------------------
def tokenize(text: str):
    return [t for t in re.findall(r"[A-Za-z][A-Za-z'-]*", text.lower())]

def top_non_stopwords(text: str, n: int = 15):
    words = [w for w in tokenize(text) if w not in STOPWORDS and len(w) > 1]
    return Counter(words).most_common(n)

# ---------------------------------------------------------------------------
# 4. Run
# ---------------------------------------------------------------------------
def main():
    print(f"Fetching abstract from: {ARTICLE_URL}")
    abstract = fetch_abstract(ARTICLE_URL)

    RAW_TXT.parent.mkdir(parents=True, exist_ok=True)
    header = (
        f"SOURCE: Tononi, G., Boly, M., Massimini, M., & Koch, C. (2016).\n"
        f"  'Integrated information theory: from consciousness to its physical "
        f"substrate.'\n  Nature Reviews Neuroscience, 17(7), 450-461.\n"
        f"DOI: {DOI}\n"
        f"URL: {ARTICLE_URL}\n"
        f"TOTAL WORDS IN ABSTRACT: {len(abstract.split())}\n"
        f"{'='*70}\n\n"
    )
    RAW_TXT.write_text(header + abstract, encoding="utf-8")

    top = top_non_stopwords(abstract, 15)
    with FREQ_CSV.open("w", encoding="utf-8") as fh:
        fh.write("rank,word,count\n")
        for i, (w, c) in enumerate(top, start=1):
            fh.write(f"{i},{w},{c}\n")

    print("\n--- RAW ABSTRACT TEXT (saved to %s) ---" % RAW_TXT)
    print(abstract)
    print("\n--- TOP 15 NON-STOP WORDS (saved to %s) ---" % FREQ_CSV)
    for i, (w, c) in enumerate(top, start=1):
        print(f"{i:>2}. {w:<22} {c}")

if __name__ == "__main__":
    main()
